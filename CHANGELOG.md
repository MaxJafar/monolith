# Monolith changes

## Automations and addon catalog

- Added visual workflows, bounded execution, saved traces, manual/event runs, interval scheduling and documented JSON imports.
- Rebuilt the addon catalog with workspace switches, search, status/category/type filters and reduced-motion support.
- Normalized bundled addon folders and metadata to Monolith while retaining explicit API route identities.
- Consolidated inherited source provenance in legal documentation. Obsolete imported archives and reports are no longer part of the product source.
