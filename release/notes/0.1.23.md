## Monolith 0.1.23 — visible dividers and Tech Lab tabs, approvable Tech Lab updates

- Divider blocks draw their line again. Pages containing dividers loaded since 0.1.21, but the line had no colour.
- Tech Lab 0.0.6 shows which section tab is open in dark mode. The active tab is underlined in teal and the others are muted.
- Server images and addon releases now build each addon's server code the same way. Tech Lab's image no longer differs from its shop release, so hosts approve Tech Lab updates without a separate schema approval. Releases now refuse to publish an addon whose two builds differ.
- Includes the 0.1.22 live Tech Lab dashboard and sidebar Favourites, the 0.1.21 edge-to-edge covers and smoother full width, the 0.1.20 schedule page properties, the 0.1.19 removal of the manual Restore previous version button, and earlier fixes back to 0.1.15.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files.

**Server administrators:** this release keeps the 0.1.14 schema fingerprint, so a server on 0.1.14 or later updates automatically through the supervisor. Servers older than 0.1.14 still need the 0.1.14 planned migration first. Tech Lab's database schema is unchanged since 0.1.14. To install or update addons from the shop, set `MONOLITH_ADDON_CATALOG_URL` to this release's `addon-catalog.signed.json` and, for schema-bearing addons whose tables already exist, point `MONOLITH_ADDON_SCHEMA_FILE` at this release's `addon-schemas.json`.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
