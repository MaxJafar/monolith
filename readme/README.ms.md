# Monolith

Monolith ialah ruang kerja untuk dokumen, projek, pangkalan data bersambung dan addon pilihan.

Rujuk README utama untuk persediaan pnpm, PostgreSQL, aplikasi web dan klien desktop. Urus addon melalui carian, penapis dan suis setiap ruang kerja. Automations membolehkan aliran kerja visual dengan sejarah pelaksanaan.
