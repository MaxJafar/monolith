## Monolith 0.1.24 — Finance: accounts, budgets, taxes, currencies and a wishlist

- **Finance 0.0.1** is a new addon for personal money. Add bank accounts, cards, cash, crypto wallets, deposits and debts in any currency; balances and net worth update with every entry.
- Income streams such as salary, freelance or business are renameable categories. Spending uses groups with subcategories (for example Household: rent, utilities, pet food, litter, cleaning), each with its own icon, color and monthly budget.
- Amounts use exact decimal arithmetic from the database to the screen. Every transaction keeps the exchange rate it was booked at, so a later rate change never rewrites your history, and gross − tax = net is enforced for every row.
- Currencies: market rates refresh automatically (a daily reference table for fiat, CoinGecko for crypto). Pin your own rate, such as 1 USD = 1.70 AZN, and it wins everywhere. Switch the dashboard between your currencies from the header, convert amounts, or change your main currency with every booked amount restated exactly.
- Taxes: VAT added on top or included in prices (18% on foreign digital services, from 23 August 2026), VÖEN simplified tax at 2% and 2026 salary withholding with income, social, unemployment and medical components. Enter what you received and Finance works out the gross. The Taxes page shows what was withheld and what to set aside, per income stream and per month.
- Wishlist: lists with prices that calculate themselves (price × quantity + shipping + VAT, converted live). Switch on **Bought** and the item becomes an expense in the paying account; switch it off and exactly that expense is removed.
- Plan: recurring income, rent, bills and subscriptions post each occurrence exactly once, project your year month by month, and a deposit calculator shows interest by month for any term and payout schedule.
- Dashboard: week, month, year and all-time views with animated cash flow, a category donut, income streams with their tax, budgets, upcoming items, the wishlist and a net worth trend. Every chart can be read with the keyboard or as a table, and motion follows your reduced-motion setting.
- Includes the 0.1.23 divider and Tech Lab fixes and earlier fixes back to 0.1.15.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files.

**Server administrators:** Finance adds new `finance__*` tables, so this release changes the schema fingerprint and the supervisor shows it as a planned migration instead of installing it automatically. Back up the database and storage, run the migration service with the 0.1.24 image, verify the server, then set the supervisor's schema configuration to the 0.1.24 fingerprint and restart it. The migration only creates tables, with owner row security; existing data is not changed. Servers older than 0.1.14 still need the 0.1.14 planned migration first. To install or update addons from the shop, set `MONOLITH_ADDON_CATALOG_URL` to this release's `addon-catalog.signed.json` and point `MONOLITH_ADDON_SCHEMA_FILE` at this release's `addon-schemas.json`.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
