Monolith brings pages, structured records, projects and daily tools into a workspace you can run on your own infrastructure. Use the browser or connect a Windows or macOS client to your host.

**Make space for what matters.** Capture an idea in a page, turn it into a project and keep the next action visible on your dashboard. The [first-workspace walkthrough](/docs/quickstart) shows how those pieces fit together.

## Keep the context with the work

[Pages](/docs/pages) hold your writing and references. [Databases](/docs/databases) give structured information typed properties and connected views. [Projects and Calendar](/docs/projects-calendar) bring tasks and dates into focus, while [Rooms](/docs/rooms) keeps conversations nearby.

## Start with the essentials

Seven native sections form the foundation:

| Section   | What it is for                                               |
| --------- | ------------------------------------------------------------ |
| Calendar  | Dates, events and a view of what is coming up.               |
| Projects  | Planning work in boards, lists, timelines and Gantt views.   |
| Actions   | Today, Upcoming, High priority and Completed.                |
| Rooms     | Workspace conversations and collaboration.                   |
| Docs      | Nested pages, rich writing, references and linked knowledge. |
| Dashboard | Connected widgets arranged around your day.                  |
| Databases | Structured records, typed properties and saved views.        |

Records keep their identities when they appear in another view. A database record shown in Calendar is still the same underlying record.

## Add what fits

**Addons** are optional tools with their own workspace surfaces, such as Atlas, Automations, Agents or Gym. **Widgets** are compact views you place on a dashboard or pin to the sidebar, such as Calendar or Action agenda.

The **Addons and Widgets** section separates installing a package on a host from enabling it in a workspace. The public [collection](/addons) explains each tool; installation happens inside your running Monolith app.
