## Monolith 0.1.20 — schedule as page properties

- Events and dated pages show Repeat, Reminders, Guests and Time zone as page properties instead of a separate Schedule & guests panel. Hide properties hides them with the rest.
- Click a property to edit it in a small popover; changes save when the popover closes. Repeat summarizes the rule, for example Weekly on Wed. Reminders lists times such as 10 min before. Guests shows who is invited and their RSVP. Time zone has a searchable list, the All day switch and the start and end date properties.
- Includes the 0.1.19 removal of the manual Restore previous version button, the 0.1.18 Day, Week and Month calendar widget views and large page icons, the 0.1.17 page icon and cover popover, the 0.1.16 desktop window fixes and the 0.1.15 page editing and security fixes.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files.

**Server administrators:** this release keeps the 0.1.14 schema fingerprint, so a server on 0.1.14 or later updates automatically through the supervisor. Servers older than 0.1.14 still need the 0.1.14 planned migration first. If you are upgrading from 0.1.14, see the 0.1.15 notes for `MONOLITH_AUTH_ADMIN_IDS`.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
