## Monolith 0.1.21 — edge-to-edge covers and smoother full width

- A page cover now runs edge to edge beneath the top bar, as in Notion, whatever the page width. Its height follows the window, and the page icon rests on its lower edge in line with the title.
- Switching a page between standard and full width eases the content open or shut instead of jumping. Reduce Motion switches instantly.
- Settings closes when you press anywhere outside it, as Escape does. An open dropdown inside Settings closes first.
- Pages containing a divider load again, including dividers placed directly on a page.
- The sidebar shows Journal instead of a missing label, and the icon picker's search box shows its Search label, in every language.
- Includes the 0.1.20 schedule page properties, the 0.1.19 removal of the manual Restore previous version button, the 0.1.18 Day, Week and Month calendar widget views and large page icons, the 0.1.17 page icon and cover popover, the 0.1.16 desktop window fixes and the 0.1.15 page editing and security fixes.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files.

**Server administrators:** this release keeps the 0.1.14 schema fingerprint, so a server on 0.1.14 or later updates automatically through the supervisor. Servers older than 0.1.14 still need the 0.1.14 planned migration first. If you are upgrading from 0.1.14, see the 0.1.15 notes for `MONOLITH_AUTH_ADMIN_IDS`.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
