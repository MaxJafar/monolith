## Monolith 0.1.22 — live Tech Lab dashboard and sidebar favourites

- Tech Lab 0.0.5 turns its widgets into a live dashboard you can move and resize on any page or the Tech Lab board. Machines show online state, live CPU and RAM charts, load, disks and the top five processes from Glances. Services appear as tiles grouped by category, with their app icon, status, latency and a 24-hour availability strip.
- The new Uptime widget shows each monitor's last 24 hours as a strip, with availability and latency. Put a public Uptime Kuma status page URL in its filter to mirror Kuma's heartbeats instead of Tech Lab's own monitors. The new Machines widget lists every device with CPU and RAM meters and uptime.
- Tech Lab reads only process names and usage from Glances; command lines and user names are dropped on the server.
- The sidebar's workspace views are now Favourites. Add workspace views, pages, addons and widgets, drag them into order, and remove them. Your current views and pinned sidebar widgets carry over.
- Includes the 0.1.21 edge-to-edge covers, smoother full width, Settings closing on an outside press and divider fix, the 0.1.20 schedule page properties, the 0.1.19 removal of the manual Restore previous version button, and earlier fixes back to 0.1.15.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files.

**Server administrators:** this release keeps the 0.1.14 schema fingerprint, so a server on 0.1.14 or later updates automatically through the supervisor. Servers older than 0.1.14 still need the 0.1.14 planned migration first. Tech Lab's database schema is unchanged since 0.1.14. To install or update addons from the shop, set `MONOLITH_ADDON_CATALOG_URL` to this release's `addon-catalog.signed.json` and, for schema-bearing addons whose tables already exist, point `MONOLITH_ADDON_SCHEMA_FILE` at this release's `addon-schemas.json`.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
