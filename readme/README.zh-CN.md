# Monolith

Monolith 是用于文档、项目、关联数据库和可选扩展的工作空间。

请参阅主 README，了解 pnpm、PostgreSQL、网页应用和桌面客户端的配置方式。在扩展管理器中使用搜索、筛选和开关管理当前工作空间的工具。Automations 提供可视化工作流和执行记录。
