## Monolith under 0BSD

- First-party Monolith code is now licensed under Zero-Clause BSD (0BSD), including commercial use, modification and redistribution. Third-party dependencies retain their notices and licenses; earlier releases retain their original terms.
- Replaced the remaining inherited core implementations, shared controls, authentication services, tooling and translations.
- Retired inherited addon packages. Atlas, Automations, Agents, Redraw, Gym and Tech Lab remain available. Calendar, Journal, Projects and Rooms are native workspace features.
- Published new patch versions of all six custom addons for this host release. Update installed addons from Addons and Widgets after upgrading the server.
- Improved account creation, connection recovery, file ownership checks, interrupted downloads and addon asset loading.
- Updated the public website, installation guides and license information.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files. The previous version remains available for runtime rollback.

**Server administrators:** this release changes the schema fingerprint. Back up the database, uploaded files and addon state, apply the release's migration in a maintenance window, then establish the new updater baseline. Automatic installation will pause for this planned migration. Do not override that check. Runtime rollback does not reverse schema changes. Retired addon data is not automatically deleted.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
