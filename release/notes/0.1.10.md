## Verification notes

- Windows clients download and verify this update automatically, but testing from 0.1.9 found that the background restart can stall. Use **Settings → Updates → Restart and install** to finish this upgrade. A correction is being prepared for a subsequent release.
- The small Windows window icon is present; the large taskbar icon still needs a correction.
- The Mac mini completed the automatic upgrade from 0.1.9, preserved its server profile and retained 0.1.9 for rollback. macOS requested Keychain approval before restoring the saved session because these builds use ad-hoc signatures.

## Projects, Actions and Calendar

- Projects now has a gallery with cover images, visible properties, hover details and progress calculated from linked actions.
- Table Type distinguishes projects, actions, events, notes and general databases. Actions link to individual projects, with the same relationship visible from either side.
- Actions includes Inbox, Today, Agenda, To do and Completed views, plus focus widgets. Pomodoro sessions can select and complete actual workspace tasks.
- Calendar uses a wider layout, a mini-month and calendar source rail, compact controls and floating event editors. Failed saves preserve the draft for retry.
- Sidebar items support dragging from the whole row, including in the Windows app. Dropdowns and scheduling controls follow the shared Monolith UI.
- The Windows app now sets its Monolith window icon explicitly and includes the PNG icon in the native bundle.

This release preserves existing records and relationships. Self-hosted upgrades should retain a database backup and review add-on schema changes before activation.
