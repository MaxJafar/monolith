# Monolith

Monolith 是用於文件、專案、關聯資料庫和選用擴充套件的工作空間。

請參閱主 README，了解 pnpm、PostgreSQL、網頁應用程式和桌面用戶端的設定方式。在套件管理器中使用搜尋、篩選和開關管理目前工作空間的工具。Automations 提供視覺化工作流程和執行紀錄。
