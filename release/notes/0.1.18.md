## Monolith 0.1.18 — calendar views and page icons

- The Calendar widget has Day, Week and Month views. Hovering a day or an event shows an animated preview, and repeating events set up in Schedule & guests now appear. In the sidebar, the month shows dots for busy days and the week becomes a list.
- Upcoming events shows each event's day and time. Hovering Open calendar previews the next few days.
- Page icons appear large above the title and rest on the cover, on documents and on database and project pages. Add icon and Add cover appear when you hover a page. The icon and cover popover adds link and position options for cover images.
- Schedule & guests is grouped into date and time, repeat, reminders and guests, with switches for All day and email reminders, reminder chips such as 1 hour and 1 day, and a message when there is nobody to invite.
- Project cards show the project icon above the title, list next actions in the card instead of over the cover, and use a compact status control.
- Includes the 0.1.17 page icon and cover popover, the 0.1.16 desktop window fixes and the 0.1.15 page editing and security fixes.

### Updating

Windows and macOS clients download authenticated updates automatically, then restart after two idle minutes in the background with edits saved. Server connection settings, saved sessions and drafts are kept outside application files. The previous version remains available for runtime rollback.

**Server administrators:** this release keeps the 0.1.14 schema fingerprint, so a server on 0.1.14 or later updates automatically through the supervisor. Servers older than 0.1.14 still need the 0.1.14 planned migration first. If you are upgrading from 0.1.14, see the 0.1.15 notes for `MONOLITH_AUTH_ADMIN_IDS`.

The Windows installer is unsigned. The macOS application has an ad-hoc signature and is not notarized. macOS may request approval to use the saved Monolith Keychain item after an update. Update manifests and addon catalogs remain signed with the existing release keys.
