Atlas is an optional knowledge addon. It brings maps, linked pages, backlinks and contextual discovery into a visual view of your existing workspace.

## Enable Atlas

Install Atlas through your host’s [addon collection](/docs/addons), then enable it in the intended workspace. Atlas appears as an addon when enabled; it is not a permanent native section.

## Follow a connection

Use the map and accessible page list to find a page or record. Selecting an item brings its neighborhood and relationship context into focus. Open the original workspace document when you want to read or edit it.

The graph is derived from the same content model used by Docs and Databases. It does not maintain an independent copy of every page.

## Read the layers

Atlas can show canonical links, explicit tag hubs, inferred topics and contextual suggestions from the configured search index. Labels and line styles distinguish different kinds of relationships.

A contextual suggestion is not an authored link. Similarity is a retrieval score, not a probability. Editors can deliberately save an explicit connection using the regular workspace controls.

## Keep the map useful

Filter the page list, focus a neighborhood, adjust spacing or labels, and use fit controls when the view becomes crowded. Pause layout movement when you want a stable view. Reduced-motion preferences remove decorative movement while retaining controls.

Index coverage and optional model configuration affect contextual discovery. Keyword-based exploration remains useful without embeddings. Read coverage indicators before assuming every page has been analyzed.

## Editing and permissions

Opening a node uses the original page or record route. Deleting an explicit connection does not delete the pages. Derived relationships such as hierarchy and database membership are read-only in the map.

Workspace roles still apply. A viewer can explore accessible information without gaining permission to edit the source content.
