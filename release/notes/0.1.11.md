## Desktop update and Windows icon fixes

- Automatic installation now checks whether the native app window is in the background, including minimized Windows windows. It waits for two minutes of inactivity and saved edits, and checks again before restarting.
- Returning to the app or a failure to read the native window state postpones installation.
- Windows now loads the Monolith icon for both the small window icon and the large taskbar icon.
- Existing server connections, saved sessions, workspace data and update preferences are preserved.

### Upgrading

Windows 0.1.9 and 0.1.10 can download this release automatically, but their restart bug can prevent automatic installation. Use **Settings → Updates → Restart and install** once to receive the correction. Later updates use the corrected background detection.

The Windows installer is unsigned. The macOS app uses an ad-hoc signature and is not notarized; macOS may request permission to use the saved Monolith Keychain item after installation. Update packages remain authenticated by signed release metadata and verified checksums.

The hosted server uses the existing automatic update service. This release does not introduce a database schema change.
